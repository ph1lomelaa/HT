# Hickmet — состояние работ

Обновлено: 16 октября 2026. Основной сценарий — Telegram Mini App; отдельный сайт тоже поддерживается.

## Готово локально

- Исправлен разбор пакетов, людей, отелей, дат; отдельные изменения для каждой комнаты.
- Mini App и сайт в `pligrim_bot/web`: пакет/ручное заполнение → паломники → проживание → услуги → необязательный перелёт → проверка → PDF.
- Дополнительная страница перелёта включается пользователем; ручные рейсы любой авиакомпании.
- Подписанная авторизация Telegram; отдельный сайт подтверждает вход в боте.
- Генерация и фоновая отправка PDF только в чат подтверждённого пользователя; скачивание PDF/ZIP.
- Удалены перечисленные пользователем промотексты и большой промоблок. Главная начинается с карточек оформления.
- Адрес настроен в локальном `.env`: `https://voucherhickmet.duckdns.org`.
- После добавления общих рабочих таблиц проверены 85 автоматических тестов (бот + API Mini App), включая порядок месяцев, смену года, фильтрацию кешированного меню и доступность листов составных таблиц; доставка в тестах имитировалась.
- Скачивание внутри Telegram поддерживает повторные запросы и загрузку частями по ссылке со сроком 90 секунд; проверены HEAD, GET, Range и истечение ссылки.
- В README описаны запуск сайта, обновление через существующий Caddy и откат старого бота; у web-контейнера есть healthcheck.
- Добавлена безопасная команда `python -m pligrim_bot.diagnostics`: список доступных документов и распознанных месяцев, без ключей и строк паломников.
- По последнему запросу показываются только текущий месяц и будущие (Asia/Almaty), в порядке дат; прошлые скрываются автоматически в боте и Mini App, включая смену года.
- Проверка текущих Credentials: доступно 11 документов; после фильтра на октябрь 2026 остаются October 2026, November 2026, December 2026, January 2027.
- Исправленный парсер проверен на 12 реальных листах: 19 пакетов, 58 PDF; 10 незаполненных пакетов блокируются до исправления.

## Что обязательно доделать

1. Закончить проверку интерфейса в Telegram-подобном мобильном размере и на компьютере, включая скачивание файлов.
   Автоматизация Chrome прерывается сообщением о смене приложения пользователем; визуальная проверка пока не завершена.
2. Выполнено: получены Caddyfile, путь монтирования `/root/infra/Caddyfile` и подходящая сеть `infra_infra_net`.
3. Разместить обновлённый код на сервере `65.21.188.181`, проверить серверный Google-ключ и все месяцы.
4. Подключить web-контейнер к существующей сети Caddy; добавить новый домен и проверить TLS. Второй Caddy НЕ запускать.
5. Обновить старый `pilgrim-bot`, исключив одновременный polling двух ботов с одним токеном. Сохранить резервную копию старого запуска.
6. Проверить реальный `/start` → открытие Mini App → выбор пакета → PDF в личном Telegram-чате на телефоне и компьютере.
7. Проверить отдельный сайт: подтверждение входа в боте, выбор пакета, скачивание.

## Что известно о сервере

- Ubuntu 24.04, адрес `65.21.188.181`.
- Caddy работает как Docker-контейнер `caddy`, образ `caddy:2-alpine`, порты 80 и 443 уже заняты им.
- Caddyfile на хосте: `/root/infra/Caddyfile`, внутри контейнера: `/etc/caddy/Caddyfile` (bind mount одного файла).
- Подходящая сеть: `infra_infra_net`; Caddy также подключён к сетям других проектов.
- По последнему серверному выводу: коммит 8117c2a получен, bot/web образы собраны, ht-web-1 Healthy, Caddy видит /health и доменный блок добавлен; validate/reload успешны.
- Проверка HTTPS завершилась TLS alert internal error. Скрипт остановился ДО остановки pilgrim-bot и запуска нового bot. Требуется диагностика DNS/ACME по логам Caddy и отдельное переключение бота.
- По уточнению пользователя JUNE-JULY-AUGUST 2026/27 и RAMADAN/SHAWWAL-2026 добавлены как общие рабочие таблицы, доступные независимо от фильтра старых месяцев; их листы не скрываются из-за неоднозначного года.
- Актуальный способ доставки кода: пользователь публикует изменения в GitHub, на сервере выполняется git pull. Ранее подготовленный архив больше не используется.
- По уточнению пользователя локальный Caddyfile удалён; Caddy остаётся только в инфраструктуре. Compose запускает bot/web и подключает web к `infra_infra_net` по умолчанию.
- Старый бот: контейнер `pilgrim-bot`, образ `pilgrim-bot:latest`. Он ещё показывает старое меню и только июнь.
- В GitHub-коммите `1c1e173` обнаружен ручной фильтр February 2026, December 2025, January 2026 — возможная причина отсутствующих месяцев. В обновлённом коде фильтр задаётся через EXCLUDED_PILGRIM_MONTHS и по умолчанию пуст. Локальный Google-ключ видит 11 документов; полный результат нужно проверить на сервере.
- SSH с ключом `~/.ssh/id_ed25519` требует passphrase. Пользователь вошёл вручную; автоматическое SSH-подключение пока не авторизовалось.
- Секреты, passphrase и приватные ключи не запрашивать в чате, не включать в архив/образ/Git.
